# Brand icons

Technology logos used by `docs/tools/diagrams.py`, which inlines them into the diagrams in
`docs/assets`. Nothing is loaded when a diagram is viewed.

| Source | Version | Licence |
|---|---|---|
| [Simple Icons](https://simpleicons.org) | 13.21.0 | CC0 1.0 |

Each logo is drawn in its brand's official colour. Logos are trademarks of their owners and appear only
to identify the technology each part of the system uses. Playwright, secrets and logs have no logo in
the set, so the generator draws small glyphs for them.
